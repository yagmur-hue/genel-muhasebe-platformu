# Genel Muhasebe Çalışma Platformu



Genel muhasebe, TDHP ve yevmiye kaydı çalışmalarına yönelik tek dosyalık, interaktif eğitim platformu.



## Kullanım



`index.html` dosyasını açın. Çalışma notları ve işaretlemeler tarayıcının `localStorage` alanında tutulur; JSON yedeği indirip aktarabilirsiniz.



## GitHub Pages



Site `main` dalının kök klasöründen yayımlanır. Harici backend kullanılmaz. Tailwind CDN için internet bağlantısı gerekir.
